# Contributing to Prompt Gallery

First off, thank you for considering contributing to the **Prompt Gallery**! It's people like you that make this the ultimate collection of world-class AI prompts.

## The "Gold Standard" Requirement

We don't accept standard or basic prompts. Every prompt in this gallery must follow our "Copy-Paste-Enjoy" philosophy. This means your prompt should:
- Require little to no tweaking from the end user.
- Consistently produce jaw-dropping, high-quality results.
- Bypass standard AI limitations to force exceptional output.

## How to Contribute

1. **Fork the Repository** 
   Fork the project to your own GitHub account.

2. **Create a Branch**
   Create a new branch for your prompt (`git checkout -b add-super-cool-prompt`).

3. **Add Your Prompt**
   - Navigate to the appropriate category folder (`/App`, `/Pictures`, `/Videos`, or `/Website`).
   - Create a new Markdown (`.md`) file or add your prompt to an existing relevant file.
   - Make sure your prompt is clearly formatted and ready for users to simply copy and paste.

4. **Commit Your Changes**
   Commit your changes with a clear and descriptive commit message (`git commit -m 'Add state-of-the-art cinematic video prompt'`).

5. **Push to the Branch**
   Push your changes to your fork (`git push origin add-super-cool-prompt`).

6. **Open a Pull Request**
   Open a Pull Request (PR) against the `main` branch of this repository. In your PR description, please mention:
   - What the prompt does.
   - Which AI model(s) it is optimized for (e.g., Midjourney v6, GPT-4).
   - An example of the output it generates (if possible).

## Code of Conduct
By participating in this project, you agree to maintain a respectful and welcoming environment for everyone.

Happy prompting! 🌌
