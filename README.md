# ai-prompts-gallery

A curated, copy-paste repository of battle-tested AI system prompts, few-shot templates, and prompt engineering frameworks for applications, automated agents, media synthesis, and code assistants.

## Architecture and Taxonomy

* **Format**: Structured Markdown & JSON templates
* **Target Models**: OpenAI GPT-4o, Anthropic Claude 3.5 Sonnet, DeepSeek, Meta LLaMA 3
* **Categories**: Web Engineering, Graphic & UI Design, Backend Architecture, Automated Agents

## Key Features

* **Application Prompts**: Structured context primers for multi-agent workflows, code generation, and API schema design.
* **UI/UX Prompts**: Precise aesthetic directives avoiding generic AI design patterns and enforcing clean design systems.
* **System Directives**: Robust system-prompt constraints with prompt injection defense guidelines.

## Getting Started

### Installation
```bash
git clone https://github.com/itsgoharrehman/ai-prompts-gallery.git
cd ai-prompts-gallery
```

Browse the prompt library in the `prompts/` directory or view indexed markdown collections.
